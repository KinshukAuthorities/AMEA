# Optional generated 2D references

Use image generation only when selected or authorized. The default [drawn workflow](workflow-selection.md) authors its own editable contours without a generator. Supply the actual design references, pose and view constraints. Inspect anatomy, perspective and consistency and record provenance. Generated references do not prove native editability or animation.

If a user-selected generator is unavailable, explain the gap and ask before changing that method. Continue independent work. Do not install inference stacks by habit.
